# Blackjack
Telegram Blackjack Bot is a Python-based gambling-style game bot that lets users play Blackjack against a dealer, place bets, manage an in-app balance, and earn money through mini math challenges.

## Features

- Full Blackjack gameplay (Hit / Stand mechanics)
- Betting system with virtual in-app currency
- Automated dealer logic (draws until 17 or higher)
- Persistent user data storage using pickle
- Basic earning system via math challenges
- Interactive Telegram interface with inline and reply keyboards
- Multi-user support with individual game states

---

## Technologies Used

- Python 3
- pyTelegramBotAPI (telebot)
- pickle (data serialization)
- random (game logic)
